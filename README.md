# Lager Stückliste (PWA)

Offline-fähige PWA: Lager-Stückliste-PDF öffnen und ausfüllen (Zeilen markieren, Stempel, Apple Pencil).

## Lokal starten

```bash
python3 -m http.server
```

Dann http://localhost:8000

## Hinweise

- Standard-Initialen bei Neuinstallation: **SG**
- PDF-Ordner (Windows Chrome/Edge) und Stempel-Farbe werden lokal gemerkt
- Demo-PDFs sind bewusst **nicht** im Repository (vertrauliche Kundendaten)
